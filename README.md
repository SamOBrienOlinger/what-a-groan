## Getting started

Clone the workspace to inspect or develop it:

```bash
git clone https://github.com/SamOBrienOlinger/what-a-groan.git
cd what-a-groan
```

There is no application to install or start on the default branch yet. A useful next implementation should add an entry point, reproducible dependency configuration and a small verification procedure.
